# .github

Organization-wide policies and default community files for the `buspilot-org` GitHub organization.

- [`docs/agent-policy.md`](docs/agent-policy.md): rules for AI agents (and people) working in Buspilot repositories, including the mandatory self-review for pull requests.
- [`.github/pull_request_template.md`](.github/pull_request_template.md): default pull request template for repositories in this organization that do not have their own.
